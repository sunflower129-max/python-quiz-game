# Python 퀴즈 게임

## 프로젝트 개요
Python으로 만드는 터미널 기반 객관식 퀴즈 게임입니다.

## 퀴즈 주제와 선정 이유
퀴즈 주제는 수학 공식 맞히기입니다.
수학 공식을 문제로 풀면서 복습할 수 있도록 이 주제를 선택했습니다.
각 문제는 4개의 선택지 중 올바른 공식을 고르는 방식으로 구성합니다.

## 실행 방법
프로그램 구현 후 작성할 예정입니다.

## 기능 목록
다음 기능을 구현할 예정입니다.

- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 보기
- 최고 점수 확인
- 종료

## 파일 구조
개발하면서 작성할 예정입니다.

## 데이터 파일 설명
프로젝트 루트의 state.json에 퀴즈와 최고 점수를 저장할 예정입니다.
