# 수학 공식 퀴즈 게임

## 프로젝트 개요
Python으로 만든 터미널 기반 객관식 퀴즈 게임입니다.
수학 공식 문제를 풀거나 직접 추가할 수 있으며, 퀴즈와 최고 점수를 파일에 저장합니다.

## 퀴즈 주제와 선정 이유
퀴즈 주제는 수학 공식 맞히기입니다.
수학 공식을 문제로 풀면서 복습할 수 있도록 이 주제를 선택했습니다.
각 문제는 4개의 선택지 중 올바른 공식을 고르는 방식으로 구성했습니다.

## 실행 방법
### 실행 환경
- Python 3.10 이상
- 외부 라이브러리 설치 불필요
- Python 표준 라이브러리인 json과 pathlib 사용

### 실행 순서
1. 프로젝트 폴더를 VS Code에서 엽니다.
2. 터미널 → 새 터미널을 선택합니다.
3. 프로젝트 폴더 위치에서 다음 명령어를 실행합니다.

```powershell
python main.py
```

4. 메뉴에 표시된 번호를 입력합니다.

## 기능 목록
- 퀴즈 풀기: 등록된 문제를 순서대로 풀고 정답과 오답을 확인합니다.
- 결과 표시: 모든 문제를 풀면 맞힌 문제 수를 표시합니다.
- 퀴즈 추가: 문제, 선택지 4개, 정답 번호를 입력해 추가하고 저장합니다.
- 퀴즈 목록: 등록된 문제, 선택지, 정답 번호를 확인합니다.
- 최고 점수 확인: 한 게임에서 맞힌 문제 수의 최고 기록을 확인합니다.
- 데이터 유지: 프로그램을 종료하고 다시 실행해도 퀴즈와 최고 점수가 유지됩니다.
- 입력 처리: 빈 입력, 숫자가 아닌 입력, 허용 범위 밖의 번호를 처리합니다.
- 안전한 종료: Ctrl+C 또는 입력 종료가 발생하면 안내 후 저장을 시도하고 종료합니다.
- 파일 오류 처리: 저장 파일이 없거나 손상된 경우 기본 퀴즈와 기록 없음 상태로 시작합니다.
- 파일 읽기·쓰기 실패 시 안내 메시지를 출력합니다.

## 코드 구조
### Quiz 클래스
개별 퀴즈를 관리합니다.

- question: 문제
- choices: 선택지 4개
- answer: 정답 번호인 1~4
- display(): 문제와 선택지 출력
- check_answer(): 정답 여부 확인
- to_dict(): 저장할 딕셔너리로 변환

### QuizGame 클래스
게임 전체를 관리합니다.

- quizzes: 퀴즈 목록
- best_score: 최고 점수
- show_menu(): 메뉴 출력
- play_quiz(): 퀴즈 진행과 최고 점수 갱신
- add_quiz(): 새 퀴즈 등록
- show_quizzes(): 퀴즈 목록 출력
- show_score(): 최고 점수 출력
- save_state(): 파일 저장
- load_state(): 파일 불러오기
- run(): 메뉴 반복과 종료 처리

### 공통 입력 함수
- get_number(): 허용 범위 안의 정수를 입력받습니다.
- get_text(): 비어 있지 않은 글자를 입력받습니다.

## 데이터 파일 설명
### 위치와 저장 방식
- 데이터는 main.py와 같은 폴더인 프로젝트 루트의 state.json에 저장합니다.
- UTF-8 인코딩을 사용합니다.
- 퀴즈를 추가하거나 게임을 끝까지 풀면 저장합니다.
- 프로그램을 종료할 때도 저장을 시도합니다.

### 데이터 구조 예시
아래는 구조를 설명하기 위해 퀴즈 하나만 표시한 예시입니다.

```json
{
  "quizzes": [
    {
      "question": "직사각형의 넓이를 구하는 공식은?",
      "choices": [
        "가로 + 세로",
        "가로 × 세로",
        "(가로 + 세로) × 2",
        "가로 ÷ 세로"
      ],
      "answer": 2
    }
  ],
  "best_score": null
}
```

- quizzes: 퀴즈 목록
- question: 문제 내용
- choices: 선택지 4개
- answer: 정답 번호
- best_score: 한 게임에서 맞힌 문제 수의 최고 기록
- null: 아직 게임을 끝까지 푼 기록이 없는 상태
- 0: 게임을 끝까지 풀었지만 맞힌 문제가 없는 기록

### 파일이 없거나 손상된 경우
- 파일이 없으면 기본 퀴즈 5개와 기록 없음 상태로 시작합니다.
- JSON 문법이나 데이터 구조가 잘못되면 안내 후 기본 데이터로 시작합니다.
- 이후 저장에 성공하면 현재 데이터로 state.json을 생성하거나 덮어씁니다.

## 점수 규칙
- 한 문제를 맞히면 1점입니다.
- 모든 문제를 끝까지 풀었을 때 최고 점수와 비교합니다.
- 처음 완료한 게임이거나 기존 최고 점수보다 높으면 갱신합니다.
- 중간에 중단한 게임은 점수에 반영하지 않습니다.
- 문제 수가 달라져도 최고 점수는 정답 수를 기준으로 비교합니다.
